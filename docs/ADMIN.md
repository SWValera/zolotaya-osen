# Админка

Страница управления: `https://zolotayaosen.kz/admin/`. Вход — по паролю. Цены, телефон, порядок фотографий и сами загруженные изображения хранятся в Cloudflare KV в аккаунте владельца. Отдельный GitHub token не используется.

На странице можно изменить телефон, цены и единицы оплаты для домиков, A-frame, бань и беседок; добавить, удалить, переставить фотографии и изменить подписи у всех объектов. Новые фотографии уменьшаются до 1800 px по длинной стороне, сжимаются в WebP и сохраняются в том же хранилище. После нажатия «Сохранить» изменения сразу доступны публичному сайту.

Пароль создаёт владелец сайта скриптом `node scripts/setup-admin-password.mjs`. Он сохраняется в `.private/Золотая-осень-админ.txt` и не добавляется в Git; хеш отдельно задаётся как Worker secret `ADMIN_PASSWORD_HASH`. Вход действует 8 часов, cookie защищена флагами HttpOnly, Secure и SameSite=Strict; изменения требуют CSRF-токена и same-origin запроса.
