## Что уже сделано

Разработан статический сайт базы отдыха «Золотая осень» на русском языке. Основной адрес `https://zolotayaosen.kz/` подключён к Cloudflare Worker; технический `workers.dev` адрес остаётся резервным. Главный экран использует предоставленную владельцем фотографию интерьера большого A-frame. Обновлённое направление оформления — хвойно-зелёная и тёплая каменная палитра, Manrope с выразительной системной антиквой, 3D-наклон фотографии и карточек, медленное движение кадра и плавное появление блоков при прокрутке. План территории остаётся основой выбора и расположен ниже на главной.

Предоставленный пользователем генплан сохранён без перерисовки. Размер исходного изображения — 1084 × 1280. WebP-копия имеет те же размеры. SVG-области и изображение используют одну систему координат и масштабируются совместно.

Всего в данных 22 объекта:

- 7 небольших домиков вдоль реки;
- 2 домика в верхней части;
- 1 большой A-frame;
- 2 бани;
- 3 беседки;
- бассейн, бар, администрация, пляж, место для рыбалки, парковка и вход.

Все объекты имеют карточки. У всех 15 домиков, бань и беседок есть отдельные кликабельные зоны. Работают подсветка, название при наведении, выбор из списка, фильтры, плавное приближение, закрытие карточки и возврат к общему виду. На телефоне встроенная карта сохраняет прокрутку страницы; полноэкранный режим позволяет увеличивать двумя пальцами и перемещать одним. Карточки на телефоне открываются снизу.

Восемь фото большого A-frame и фото администрации предоставлены владельцем и добавлены в локальные галереи соответствующих карточек. Главная использует фото A-frame в hero и дополнительную мозаику из четырёх снимков с переходом в галерею. Меню связывает проживание, бани, территорию и контакты; отдельная строка показывает подтверждённые количества объектов. Галерея загружает выбранный снимок; пустая галерея и отсутствующий файл обработаны. Карточки показывают подтверждённое описание и готовность; непредоставленные характеристики не выдумываются. Цена, вместимость и удобства выводятся только после подтверждения. Связь со страницы и карточки ведёт на телефон администрации.

## Неизвестные данные

Для A-frame и администрации получены фотографии. Цены, валюта аренды, вместимость, число спальных мест, перечень удобств, точный адрес базы и готовность каждого здания ещё не подтверждены. Эти данные нельзя выдумывать.

Сейчас у всех объектов статус `unconfirmed` — «Готовность уточняется». Остальные поддержанные статусы: `available`, `building`, `planned`, `unavailable`. Назначать «Доступен» можно только после подтверждения. Готовность объекта не означает наличие свободных дат.

Стоковый файл природы не используется на первом экране и не выдаётся за фото базы. Онлайн-бронирования, оплаты и календаря свободных дат нет; посетители связываются с администрацией по телефону.

## Технические требования и решения

- Только HTML5, CSS3, Vanilla JavaScript и SVG. Runtime-зависимостей и сборки для сайта нет.
- Без WordPress, React, Next.js, Vue, PHP, серверной базы данных и административной панели без объективной необходимости и согласования новой задачи.
- Все изображения и шрифт хранятся в проекте; платные API и внешние платные хранилища не нужны.
- Размещение — Cloudflare Workers Static Assets. Не подключать платные ресурсы, R2, D1 или KV.
- Не менять расположение зданий и не перерисовывать генплан. Для нового объекта добавлять точный контур в координатах исходного изображения. Без подтверждённого контура объект может появиться в списке без ложной зоны на карте.
- Мобильная версия имеет приоритет. Сохранять удобную прокрутку, полноэкранный режим карты, управление касаниями и доступные элементы управления. Учитывать настройку уменьшения анимации; 3D-эффект должен мягко отключаться на устройствах без указателя.
- Семантический HTML, один H1, title и description, основные коммерческие тексты доступны без обязательного JavaScript. Не создавать дубли страниц для одинаковых домиков.
- Учитывать reduced motion, клавиатуру, фокус в диалогах, alt-тексты, скорость загрузки и локальное хранение изображений.

## Где вносить изменения

- `public/index.html` — главная страница, статические тексты и SEO-метаданные.
- `public/assets/css/styles.css` — стили и адаптивность.
- `public/assets/js/objects.js` — единственный источник данных всех объектов, их геометрии, статусов и контактов.
- `public/assets/js/app.js` — карта, жесты, карточки, галереи и меню.
- `public/assets/images/` — генплан и фотографии. Новые фото объектов помещать в `public/assets/images/objects/<id>/`.
- `public/pages/` — каталог для будущих самостоятельных HTML-страниц.
- `public/_headers` — заголовки безопасности и кэширования.
- `wrangler.jsonc` — публикация папки `public` и включённый адрес `workers.dev`.
- `scripts/generate-seo.mjs` — генерация `robots.txt`, `sitemap.xml`, canonical и `og:url` для рабочего домена.

Менять цену и описание объекта нужно в одном месте — `objects.js`. Цена имеет вид `price: { amount: <подтверждённая сумма>, currency: '<подтверждённый код валюты>' }`; `null` означает, что цена уточняется. Галерея задаётся массивом `photos` с локальными путями `src` и содержательными `alt`. Вместимость — `capacity`, спальные места — `beds`, удобства — `amenities`, текст о будущем открытии — `opening`.

Для локального запуска из корня репозитория:

```sh
python3 -m http.server 8080 --directory public
```

Открыть http://localhost:8080. Для проверки данных и синтаксиса: `npm run check`. Браузерные тесты находятся в `tests/`; Playwright нужен только для разработки и не входит в сайт.

## Публикация и доступы

Репозиторий создан владельцем и доступен подключению GitHub. Основная ветка — `main`; исходная рабочая ветка — `feat/static-resort-site`. Чужие репозитории не использовать.

Cloudflare Workers Builds публикует ветку `main` репозитория `SWValera/zolotaya-osen` (без сборки, deploy command `npx wrangler deploy`, assets `public`). Владелец подключил к Worker собственный домен `zolotayaosen.kz`; DNS обслуживают nameserver'ы Cloudflare. Изменения публикуются после push в `main`; после публикации нужно дождаться окончания Worker build и проверить live-сайт.

Секреты, API-токены и пароли в чат или репозиторий не помещать. Если интеграция GitHub возвращает `403 Resource not accessible by integration`, проверить, выбран ли именно этот репозиторий в доступах установленного приложения.

Домен `zolotayaosen.kz` подтверждён владельцем и уже подключён. Для SEO-файлов выполнено `npm run seo -- https://zolotayaosen.kz`; в рабочей копии подготовлены canonical, `og:url`, `robots.txt` и `sitemap.xml`. Не создавай дубли страниц для одинаковых домиков.
